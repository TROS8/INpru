# Skill 01: Levantamiento de requerimientos

Objetivo: traducir necesidades del cliente a reglas claras del sistema.

Pasos:
1. Documentar actores (cliente, asesor comercial, administrador).
2. Definir escenarios clave (crear, editar, enviar cotizacion).
3. Listar campos obligatorios por producto.
4. Definir reglas de negocio no negociables.
5. Acordar criterios de aceptacion por historia.

Resultado esperado:
- Documento funcional sin ambiguedades para desarrollo.
