# Skill 03: Backend orientado a reglas de negocio

Objetivo: exponer API estable que valide reglas comerciales.

Pasos:
1. Crear endpoint para alta de cotizacion.
2. Validar caracteristicas obligatorias por item.
3. Implementar calculo de subtotal y total.
4. Registrar metodo de pago y fecha prevista.
5. Proteger transiciones de estado de cotizacion.

Resultado esperado:
- API funcional con validaciones centralizadas y testeadas.
