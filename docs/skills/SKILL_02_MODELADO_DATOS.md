# Skill 02: Modelado de datos para cotizaciones

Objetivo: construir un modelo de datos consistente y escalable.

Pasos:
1. Definir entidades y relaciones.
2. Separar item de cotizacion de catalogo de producto.
3. Permitir caracteristicas flexibles por producto (key/value).
4. Modelar comentarios por item con auditoria.
5. Normalizar metodos de pago y estados.

Resultado esperado:
- Diagrama entidad-relacion y tablas iniciales listas para migraciones.
