# Skill 04: Frontend de cotizaciones usable

Objetivo: crear interfaz clara para cotizar sin errores.

Pasos:
1. Crear formulario de cotizacion por pasos.
2. Agregar tabla editable de productos cotizados.
3. Mostrar validaciones en tiempo real.
4. Habilitar comentario por producto.
5. Mostrar resumen final con totales, pago y entrega.

Resultado esperado:
- Flujo frontend completo y entendible para usuarios de negocio.
